# scan-3bb

เว็บแอปช่วยทำ **รายงานการขอเบิกค่าใช้จ่าย (ค่าอินเทอร์เน็ต 3BB)** ของแต่ละศูนย์ บ.น้ำตาลสุรินทร์
กรอกรหัสลูกค้าจากใบแจ้งหนี้ แล้วพิมพ์ใบเบิกได้ทันที

## วิธีใช้
1. หาศูนย์ด้วยวิธีใดวิธีหนึ่ง
   - **พิมพ์รหัสลูกค้า หรือหมายเลขบริการ** ต้องครบทุกตัว
   - **ลิงก์ตรง** `…/?acc=รหัสลูกค้า`
2. ตรวจตาราง และ **รอบเดือน** ที่คำนวณจากวันกำหนดชำระ (แก้เองได้)
3. ตรวจชื่อผู้จัดทำ/ผู้อนุมัติ ซึ่งเครื่องจะจำค่าที่แก้ไว้ใช้ครั้งต่อไป
4. กด **🖨️ Print** แล้วเลือกเครื่องพิมพ์ หรือบันทึกเป็น PDF

## แก้ข้อมูลศูนย์
แก้ที่ไฟล์ `data.xlsx` (ชีตแรก, แถวแรกเป็นหัวตาราง):

| ลำดับ | ชื่อ | หมายเลขบริการ | รหัสลูกค้า | ค่าบริการ | กำหนดชำระ | หมายเลขบริการสำรอง | วันที่จ่าย |
|---|---|---|---|---|---|---|---|
| 11 | ศูนย์ท่าสว่าง | A212119700542 | 410443826 | 749 | 12/11/2569 | (ถ้ามี) | 15/10/2569 |

- **วันที่จ่าย** (คอลัมน์ H): กรอกเมื่อศูนย์นั้นจ่ายแล้ว หน้าเว็บจะแสดงเป็น "✓ จ่ายแล้ว" และนับเข้ายอดจ่ายแล้ว
  เว้นว่าง = ยังไม่จ่าย / พิมพ์คำอื่นเช่น "จ่ายแล้ว" ก็ได้ / ขึ้นรอบเดือนใหม่ให้ลบคอลัมน์นี้ออกให้ว่าง

- ตั้งคอลัมน์รหัสเป็น **Text** กันไม่ให้ Excel ตัดเลข 0 หรือแปลงเป็น `4.1E+08`
- วันที่ใช้ได้ทั้ง `dd/mm/2569`, `dd/mm/2026` และวันที่แบบ Excel
- แก้แล้วบันทึกไฟล์ จากนั้นรีเฟรชหน้าเว็บ (ไม่ต้องแก้โค้ด)

## เปิดใช้งาน
ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ ดับเบิลคลิก `index.html` ตรงๆ จะโหลด `data.xlsx` ไม่ได้

| ใช้กับ | วิธี |
|---|---|
| คอมเครื่องนี้ | `powershell -ExecutionPolicy Bypass -File serve.ps1` แล้วเปิด http://localhost:8080 |
| มือถือ (ชั่วคราว) | รัน `start.cmd` แล้วเปิดลิงก์ `https://….trycloudflare.com` ที่ขึ้นมา บนมือถือ |

`start.cmd` ต้องติดตั้ง cloudflared ก่อน (`winget install --id Cloudflare.cloudflared -e --source winget`)
ลิงก์จะเปลี่ยนทุกครั้งที่เปิด และ **ใครมีลิงก์ก็เปิดได้รวมถึงดาวน์โหลด data.xlsx** อย่าส่งต่อ ใช้เสร็จให้ปิดหน้าต่าง

ถ้าจะใช้งานถาวร แนะนำให้โฮสต์บน Cloudflare Pages + Cloudflare Access (บังคับล็อกอินอีเมลบริษัท)
หรือบนเซิร์ฟเวอร์ภายในที่มีใบรับรอง HTTPS **อย่าวางบนที่สาธารณะโดยไม่มีการล็อกอิน** เพราะมีรหัสลูกค้าและชื่อพนักงาน

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ + โค้ดทั้งหมด (ค้นหา, ใบเบิก) |
| `style.css` | หน้าตา และรูปแบบตอนพิมพ์ |
| `data.xlsx` | ข้อมูลศูนย์ (สำรอง: `data.csv` คอลัมน์เดียวกัน) |
| `logo.jpg` / `logo.png` | โลโก้บริษัทบนหัวใบเบิก (ถ้าไม่มีไฟล์ จะแสดงตัวอักษร KI แทน) |
| `serve.ps1` | เว็บเซิร์ฟเวอร์ทดสอบบนเครื่อง (ไม่ต้องติดตั้ง Python/Node) |
| `start.cmd` | เปิดเซิร์ฟเวอร์ + Tunnel ให้มือถือเข้าได้ |
